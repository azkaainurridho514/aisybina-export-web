# Aisybina Export

Aisybina Export is an export website that connects international buyers with trusted suppliers and products from Indonesia.

The website provides information about available products, sourcing services, company profile, and export processes to help buyers find and source Indonesian products for international markets.

## Features

- Product showcase
- Product sourcing
- Company profile
- Export information
- Global buyer inquiries
- WhatsApp contact
- Responsive design

## Tech Stack

- Laravel
- PHP
- MySQL
- JavaScript
- jQuery
- Bootstrap
- Bootstrap Icons
- Quill Editor

## About

Aisybina Export helps international buyers discover Indonesian products and connect with suppliers for sourcing and export needs.
